# 교육생 연결 가이드 (초안)

## A. Cowork · claude.ai 커스텀 커넥터 (공개 배포 뒤)

1. `https://hub.itda.work` 에 Google 로 로그인한다.
2. 도구함에서 「KOSIS 국가통계」와 「날씨」를 담는다. KOSIS 는 설정에서 「관리자 공용 키 사용」을 켠다(개인 키를 쓰려면 [docs/tool-keys.md](tool-keys.md) 의 발급 절차를 따른다).
3. Claude(또는 Cowork) 에서 사용자 지정 → 커넥터 → 커스텀 커넥터 추가. 이름 「잇다 허브」, URL `https://hub.itda.work/mcp`. 인증은 「지금 로그인」, OAuth 클라이언트는 「Claude 의 공개 신원」.
4. 허브 로그인 화면이 뜨면 Google 로 들어가고, 동의 화면에서 도구함의 두 스코프를 확인하고 허용한다.
5. 대화에서 "인구 통계표 검색해줘", "서울 날씨 알려줘" 를 시켜 본다.
6. 허브의 「궤적」에서 방금 호출이 누구의 어떤 스코프로 남았는지 본다.
7. 도구함에서 「날씨」를 빼고 새 대화를 열면 도구 목록에서 사라진 것을 확인한다.

문제가 생기면: 커넥터를 지우고 다시 추가한다(인증 설정은 추가 뒤에 바꿀 수 없다).

## B. Claude Code (로컬 compose 로도 된다)

연결 토큰은 **화면에서 발급하지 않는다**(0.4.0 부터 사용자에게는 OAuth 커넥터만 노출한다). 운영자가 `issue_token` 커맨드로 발급해 교육생에게 건넨다.

**순서가 중요하다** — `issue_token` 은 이미 있는 계정에만 발급하고, 설정이 필요한 도구는 담을 수 있는 상태여야 한다. 아래 ①→②→③ 순으로 간다.

**① 교육생 — 먼저 가입한다**

1. 허브 주소에 접속해 **가입·로그인**한다. 계정이 없으면 다음 단계의 토큰 발급이 `사용자가 없다` 로 실패한다.
2. 개인 KOSIS 키를 쓸 사람만: 도구함 → 「KOSIS 국가통계」 설정에서 키를 넣고 「저장하고 담기」. 발급 절차는 [docs/tool-keys.md](tool-keys.md). 공용 키를 쓸 사람은 아무것도 안 해도 된다.

**② 운영자 — 토큰을 발급한다**

1. 공용 키를 쓸 거라면 `.env` 에 `SHARED_KOSIS_API_KEY` 가 실제로 들어 있어야 한다. 비어 있으면 `--shared` 를 줘도 담기가 거부된다.
2. 교육생마다 발급한다:
   - docker compose: `just token <교육생 이메일> --tools weather,kosis --shared`
   - 호스트 직접: `uv run python manage.py issue_token --email <교육생 이메일> --tools weather,kosis --shared`
3. `--shared` 는 담는 도구에 관리자 공용 키 사용을 **켜는** 플래그다. **빼도 이미 켜진 것이 꺼지지는 않는다.** 개인 키 사용자는 ①-2 에서 이미 담았으므로 `--tools` 없이 `issue_token --email <이메일>` 만 돌려도 된다(도구함은 그대로 스코프가 된다).
4. 토큰 원문은 stdout 에 한 번만 나온다(DB 에는 체크섬만). 각자에게 **비공개 경로로** 전달한다 — 강의 화면·채팅방에 띄우지 않는다.

**③ 교육생 — 붙인다**

1. 받은 토큰을 붙인다:
   `claude mcp add --transport http itda-hub <MCP 주소> --header "Authorization: Bearer <받은 토큰>"`
2. Claude Code 에서 `/mcp` 로 연결 상태를 확인하고 "서울 날씨 알려줘", "인구 통계표 검색해줘" 를 시킨다.
3. 허브의 「궤적」에서 호출이 남은 것을 본다. 「날씨」를 빼면 다음 대화의 도구 목록에서 사라진다(연결 토큰의 스코프는 도구함을 즉시 따라간다).
4. 토큰을 잃어버리거나 노출했으면 운영자에게 알린다 — 같은 명령을 다시 돌리면 새 토큰이 나오고 이전 토큰은 그 즉시 거부된다(사용자당 하나). 관리자 화면에서 폐기할 수도 있다.

커스텀 커넥터(A)는 헤더를 받지 않으므로 연결 토큰으로는 붙지 않는다. 그쪽은 공개 HTTPS + OAuth 가 길이다.
