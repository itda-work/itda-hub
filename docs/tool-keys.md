# 도구 인증키 발급 가이드

허브의 도구 중 **자격증명이 필요한 것**은 여기에 발급 절차를 적는다. 키가 필요 없는 도구(날씨)는 이 문서에 없다.

키를 쓰는 길은 둘이다.

| 길 | 누가 | 어디에 |
|---|---|---|
| **관리자 공용 키** | 운영자가 한 번 발급해 모두가 쓴다(강의 기본값) | 운영 `.env` 의 `SHARED_<설정 키>` 환경변수. DB 에 저장하지 않는다 |
| **개인 키** | 사용자가 각자 발급해 자기 도구함에만 쓴다 | 허브 도구 설정 화면(Fernet 암호화 저장, 다시 표시하지 않는다) |

둘 다 있으면 **개인 키가 이긴다**(`mcp_server/tools/credentials.py`). 설정을 마쳐야 도구가 도구함에 담긴다 — 키 없이 담아서 호출 때 거부되는 도구는 만들지 않는다.

> 키는 비밀이다. 강의 화면·채팅방·이슈·커밋에 붙여 넣지 않는다.
>
> 허브는 키를 **화면에 다시 표시하지 않고**(설정 화면은 저장 여부만 보여 준다), **도구 인자에 싣지 않으며**(궤적의 인자 칸에 남지 않는다), **상류 오류의 예외 문자열과 로그에도 싣지 않는다**(쿼리스트링을 버리고 스킴·호스트·경로만 남긴다 — `mcp_server/tools/safe.py`).

## KOSIS 국가통계 (`kosis`)

- 설정 키: `KOSIS_API_KEY` · 공용 키 환경변수: `SHARED_KOSIS_API_KEY`
- 발급처: [KOSIS 공유서비스](https://kosis.kr/openapi/) (국가데이터처)
- 비용: 무료 · 승인: **자동(즉시)** · 유효기간: **승인일로부터 2년**(만료 한 달 전부터 마이페이지에서 연장)

**절차**

1. [kosis.kr/openapi](https://kosis.kr/openapi/) 접속 → 회원가입/로그인. 통계청 **ONE-ID 통합로그인**이며, 국가통계포털(KOSIS) 회원이면 그대로 쓴다.
2. 상단 **「활용신청」** 에서 쓸 서비스를 신청한다. 이 허브의 `kosis_search` 는 **「KOSIS 통합검색」**(`statisticsSearch.do`) 을 쓴다 — 개발가이드 2.6 절이다. 이름이 비슷한 「통계목록」과 다르니 주의한다. 통계 수치까지 가져오려면 **「통계자료」** 도 함께 신청해 둔다.
3. 신청은 자동 승인된다. **마이페이지 → 활용신청 현황**에서 인증키를 복사한다.
4. 인증키는 **회원 당 1개**이고 신청한 모든 서비스에 같은 키를 쓴다.

**허브에 넣기**

- 공용(운영자): `.env` 에 `SHARED_KOSIS_API_KEY=<인증키>` 를 넣는다. 키를 **읽는 쪽은 MCP 프로세스**(`hub-mcp`)이고 담기 가능 여부를 판정하는 쪽은 **web**(`hub-web`)이므로 **두 프로세스 모두 새 환경으로 다시 떠야 한다.** compose 에서는 단순 `restart` 가 아니라 재생성이 필요하다: `docker compose up -d --force-recreate hub-web hub-mcp`. 그 뒤 교육생은 도구 설정에서 「관리자 공용 키 사용」만 켜면 된다.
- 개인: 허브 로그인 → 도구함 → 「KOSIS 국가통계」 설정 → `KOSIS_API_KEY` 에 붙여넣고 「저장하고 담기」.

**막혔을 때**

| 증상 | 원인 |
|---|---|
| 호출이 `ToolDenied` 로 거부됨 | 키가 아예 없다. 개인 키를 넣거나 공용 키 사용을 켠다(공용 키는 운영자가 `.env` 에 넣어야 실제로 존재한다) |
| 결과에 `ok: false` 와 `error_code` | KOSIS 가 돌려준 오류다. 아래 표를 본다 |

**KOSIS 오류 코드**

아래는 [개발가이드 PDF v1.0](https://kosis.kr/openapi/file/openApi_manual_v1.0.pdf) 1.4.2 절의 표다. **KOSIS 사이트의 현재 FAQ 와 코드 설명이 어긋난다는 보고가 있다**(특히 만료 코드가 `11` 인지 `12` 인지). 실제로 막혔다면 [현재 FAQ](https://kosis.kr/openapi/community/community_0401List.do) 를 먼저 확인한다. (PDF 기준, 확인일 2026-09-20)

| 코드 | 뜻 | 조치 |
|---|---|---|
| `10` | 인증키 누락 | 키가 비었거나 오타. 설정을 다시 저장한다 |
| `11` | 인증키 기간 만료 | 활용신청 유효기간(2년)이 지났다. 만료 한 달 전이라면 마이페이지에서 연장하고, **이미 만료됐다면 활용신청을 다시 한다** |
| `20`·`21` | 요청변수 누락·오류 | 허브의 버그다. 이슈를 열어라 |
| `30` | 조회결과 없음 | 검색어를 바꾼다. 키 문제가 아니다 |
| `31` | 조회결과 초과 | 호출 건수를 줄인다 |
| `40` | 호출가능건수 제한 (분당 200건) | 공용 키를 여럿이 함께 쓰면 먼저 만난다. 잠시 뒤 다시 부르거나 개인 키로 바꾼다 |
| `41` | ROW 수 제한 | KOSIS 관리자 문의 |
| `42` | 사용자별 이용 제한 | 키뿐 아니라 **IP 제한**일 수도 있다. KOSIS 관리자 문의 |
| `50` | 서버 오류 | 상류 장애다. 허브 설정 문제가 아니다 |

## 부동산 실거래가 (`realty-deals`)

- 설정 키: `DATA_GO_KR_API_KEY` · 공용 키 환경변수: `SHARED_DATA_GO_KR_API_KEY`
- 발급처: [공공데이터포털](https://www.data.go.kr/) — 국토교통부가 제공하는 실거래가 OpenAPI
- 비용: 무료 · 승인: **자동(즉시)** · 유효기간: **활용신청일로부터 2년**(연장신청 가능) · 한도: 개발계정 일 10,000 건

**절차**

1. [data.go.kr](https://www.data.go.kr/) 회원가입/로그인.
2. 쓸 서비스를 **활용신청**한다. 허브의 `realty_deals` 는 두 개를 쓴다 — 매매와 전월세가 다른 서비스다.
   - [아파트 매매 실거래가 자료](https://www.data.go.kr/data/15126469/openapi.do) (`RTMSDataSvcAptTrade`)
   - [아파트 전월세 실거래가 자료](https://www.data.go.kr/data/15126474/openapi.do) (`RTMSDataSvcAptRent`)

   둘 중 하나만 신청하면 그 갈래만 되고 다른 쪽은 `20`(활용 미승인)으로 거부된다.
3. 자동 승인이지만 **게이트웨이 동기화에 5~30 분** 걸린다. 신청 직후의 `20`·`30` 은 아직 반영이 안 된 것일 수 있다.
4. **마이페이지 → 데이터활용 → 개발계정**에서 **일반 인증키**를 복사한다. 인증키는 **계정 당 1 개**이고 신청한 모든 서비스에 같은 키를 쓴다.

> **Encoding 값이 아니라 Decoding 값을 복사한다.** 포털은 같은 키를 두 벌(Encoding/Decoding)로 보여 준다. 허브는 키를 쿼리 파라미터로 넘기며 **스스로 URL 인코딩**하므로, 이미 인코딩된 값을 넣으면 두 번 인코딩돼 상류가 `30`(등록되지 않은 서비스키)을 낸다.

**허브에 넣기**

- 공용(운영자): `.env` 에 `SHARED_DATA_GO_KR_API_KEY=<Decoding 인증키>` → `docker compose up -d --force-recreate hub-web hub-mcp`.
- 개인: 도구함 → 「부동산 실거래가」 설정 → `DATA_GO_KR_API_KEY` 에 붙여넣고 「저장하고 담기」.

**막혔을 때** — 결과의 `error_kind` 가 어디를 볼지 가리킨다(`credential`: 키·활용신청, `argument`: 호출 인자, `transient`: 잠시 뒤 재시도).

| 코드 | 뜻 | 조치 |
|---|---|---|
| `20` | 서비스 접근 거부(활용 미승인) | 위 두 서비스를 모두 신청했는지 확인. 자동 승인이라도 5~30 분 기다린다 |
| `30` | 등록되지 않은 서비스키 | Encoding 값을 넣었을 가능성이 가장 크다. Decoding 값으로 다시 저장한다 |
| `31` | 기간 만료된 서비스키 | 개발계정에서 연장신청 |
| `32` | 등록되지 않은 도메인/IP | 활용신청정보에서 도메인·IP 제한을 푼다 |
| `22` | 일일 트래픽 초과 | 공용 키를 여럿이 함께 쓰면 먼저 만난다. 개인 키로 바꾸거나 다음 날 |
| `ARGUMENT` | 허브가 막았다 | `lawd_cd` 는 법정동코드 **앞 5 자리**(시군구), `deal_ymd` 는 `YYYYMM` |

> 결과가 `ok: true`, `count: 0` 이면 **그 달에 그 지역의 거래가 없었다**는 참인 답이다. 키 문제가 아니다.

## 한국은행 경제지표 (`ecos`)

- 설정 키: `ECOS_API_KEY` · 공용 키 환경변수: `SHARED_ECOS_API_KEY`
- 발급처: [한국은행 경제통계시스템 OpenAPI](https://ecos.bok.or.kr/api/) (한국은행)
- 비용: 무료 · 승인: **자동(가입 즉시 부여)** · 유효기간: 없음 · 한도: 과도 호출 시 `ERROR-602` 로 일시 제한

**절차**

1. [ecos.bok.or.kr/api](https://ecos.bok.or.kr/api/) 접속 → **회원가입**(ECOS 회원이면 그대로).
2. **OpenAPI → 인증키 신청**. 가입 시 자동 부여되며 별도 심의가 없다.
3. **마이페이지 / 인증키 관리**에서 인증키를 복사한다.

> 키 없이 응답 구조만 보고 싶다면 인증키 자리에 `sample` 을 넣으면 최대 10 건까지 온다. 허브 설정에는 실제 키를 넣는다.

**허브에 넣기**

- 공용(운영자): `.env` 에 `SHARED_ECOS_API_KEY=<인증키>` → `docker compose up -d --force-recreate hub-web hub-mcp`.
- 개인: 도구함 → 「한국은행 경제지표」 설정 → `ECOS_API_KEY`.

**막혔을 때**

| 코드 | 뜻 | 조치 |
|---|---|---|
| `INFO-100` | 인증키가 유효하지 않음 | 앞뒤 공백을 지우고 다시 저장한다. 발급 직후면 수 분 뒤 재시도 |
| `ERROR-100` | 필수값 누락 | `stat_code` 를 줬다면 `period`·`start`·`end` 가 모두 필요하다 |
| `ERROR-101` | 주기와 날짜 형식 불일치 | `A:2024` · `S:2024S1` · `Q:2024Q1` · `M:202401` · `SM:202401S1` · `D:20240101` |
| `ERROR-400` | 검색범위 초과(60 초 타임아웃) | 기간을 줄인다 |
| `ERROR-602` | 과도한 호출로 이용 제한 | 공용 키를 여럿이 함께 쓰면 먼저 만난다. 잠시 뒤 재시도 |

> `ok: true`, `count: 0` 은 상류의 `INFO-200`(해당 데이터 없음)이다 — 기간이나 항목코드를 바꾼다.

## 환율 (`fx`)

- 설정 키: `ECOS_API_KEY` · 공용 키 환경변수: `SHARED_ECOS_API_KEY`
- 발급처·절차·오류 코드: **위 「한국은행 경제지표」 와 같다.** 환율 도구는 ECOS 의 일별 대원화환율 통계표를 읽는 얇은 프리셋이라 **같은 인증키**를 쓴다.

**그래도 설정은 도구마다 따로 한다.** 스코프가 곧 도구함이라(`tool:fx` 와 `tool:ecos` 는 따로 담긴다) 환율만 필요한 사용자에게 통계표 전체를 열어 줄 이유가 없다. 대가는 개인 키를 두 번 붙여넣는 것이고, 관리자 공용 키를 쓰면 `SHARED_ECOS_API_KEY` 하나로 둘 다 열린다. 설계 근거는 [docs/reports/H-6.md](reports/H-6.md).

## 준비 중인 도구

카탈로그에 자리는 있으나 어댑터가 없어 비공개(`enabled=False`)인 도구다. 공개될 때 이 문서에 절차를 더한다.

| 도구 | 출처 | 키 |
|---|---|---|
| 유가 (`fuel`) | 오피넷 | 미정 — 어댑터 확정 시 기재 |

## 새 도구를 더할 때 (기여자용)

자격증명이 필요한 도구를 카탈로그에 넣는다면 **이 문서에 한 절을 반드시 함께 추가한다.** 절 바로 위에 앵커 한 줄을 둔다 — `tests/test_tool_key_docs.py` 가 이 앵커로 절의 존재를 확인한다.

```markdown
<!-- tool-key: <slug> -->
## 도구 이름 (`<slug>`)
```

그 아래에 이것들을 채운다.

1. 설정 키 이름(`<TOOL>_API_KEY`)과 공용 키 환경변수(`SHARED_<설정 키>`)
2. 발급처 URL · 비용 · 승인 방식(자동/심의) · 유효기간
3. 번호 매긴 발급 절차 — 실제로 한 번 발급해 보고 화면에 보이는 메뉴 이름 그대로 적는다
4. 공용/개인 두 길의 입력 방법
5. 막혔을 때 표 — 그 API 의 키 관련 오류 코드를 어댑터가 내는 `error_code` 와 대응시킨다

`.env.example` 의 `SHARED_*` 항목에도 같은 키를 추가한다.
