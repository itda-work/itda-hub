# 도구 인증키 발급 가이드

허브의 도구 중 **자격증명이 필요한 것**은 여기에 발급 절차를 적는다. 키가 필요 없는 도구(날씨)는 이 문서에 없다.

키를 쓰는 길은 둘이다.

| 길 | 누가 | 어디에 |
|---|---|---|
| **관리자 공용 키** | 운영자가 한 번 발급해 모두가 쓴다(강의 기본값) | 운영 `.env` 의 `SHARED_<설정 키>` 환경변수. DB 에 저장하지 않는다 |
| **개인 키** | 사용자가 각자 발급해 자기 도구함에만 쓴다 | 허브 도구 설정 화면(Fernet 암호화 저장, 다시 표시하지 않는다) |

둘 다 있으면 **개인 키가 이긴다**(`mcp_server/tools/credentials.py`). 설정을 마쳐야 도구가 도구함에 담긴다 — 키 없이 담아서 호출 때 거부되는 도구는 만들지 않는다.

> 키는 비밀이다. 강의 화면·채팅방·이슈·커밋에 붙여 넣지 않는다.
>
> 허브는 키를 **화면에 다시 표시하지 않고**(설정 화면은 저장 여부만 보여 준다), **도구 인자에 싣지 않으며**(궤적의 인자 칸에 남지 않는다), **상류 오류의 예외 문자열과 로그에도 싣지 않는다**(쿼리스트링을 버리고 스킴·호스트·경로만 남긴다 — `mcp_server/tools/safe.py`).

## KOSIS 국가통계 (`kosis`)

- 설정 키: `KOSIS_API_KEY` · 공용 키 환경변수: `SHARED_KOSIS_API_KEY`
- 발급처: [KOSIS 공유서비스](https://kosis.kr/openapi/) (국가데이터처)
- 비용: 무료 · 승인: **자동(즉시)** · 유효기간: **승인일로부터 2년**(만료 한 달 전부터 마이페이지에서 연장)

**절차**

1. [kosis.kr/openapi](https://kosis.kr/openapi/) 접속 → 회원가입/로그인. 통계청 **ONE-ID 통합로그인**이며, 국가통계포털(KOSIS) 회원이면 그대로 쓴다.
2. 상단 **「활용신청」** 에서 쓸 서비스를 신청한다. 이 허브의 `kosis_search` 는 **「KOSIS 통합검색」**(`statisticsSearch.do`) 을 쓴다 — 개발가이드 2.6 절이다. 이름이 비슷한 「통계목록」과 다르니 주의한다. 통계 수치까지 가져오려면 **「통계자료」** 도 함께 신청해 둔다.
3. 신청은 자동 승인된다. **마이페이지 → 활용신청 현황**에서 인증키를 복사한다.
4. 인증키는 **회원 당 1개**이고 신청한 모든 서비스에 같은 키를 쓴다.

**허브에 넣기**

- 공용(운영자): `.env` 에 `SHARED_KOSIS_API_KEY=<인증키>` 를 넣는다. 키를 **읽는 쪽은 MCP 프로세스**(`hub-mcp`)이고 담기 가능 여부를 판정하는 쪽은 **web**(`hub-web`)이므로 **두 프로세스 모두 새 환경으로 다시 떠야 한다.** compose 에서는 단순 `restart` 가 아니라 재생성이 필요하다: `docker compose up -d --force-recreate hub-web hub-mcp`. 그 뒤 교육생은 도구 설정에서 「관리자 공용 키 사용」만 켜면 된다.
- 개인: 허브 로그인 → 도구함 → 「KOSIS 국가통계」 설정 → `KOSIS_API_KEY` 에 붙여넣고 「저장하고 담기」.

**막혔을 때**

| 증상 | 원인 |
|---|---|
| 호출이 `ToolDenied` 로 거부됨 | 키가 아예 없다. 개인 키를 넣거나 공용 키 사용을 켠다(공용 키는 운영자가 `.env` 에 넣어야 실제로 존재한다) |
| 결과에 `ok: false` 와 `error_code` | KOSIS 가 돌려준 오류다. 아래 표를 본다 |

**KOSIS 오류 코드**

아래는 [개발가이드 PDF v1.0](https://kosis.kr/openapi/file/openApi_manual_v1.0.pdf) 1.4.2 절의 표다. **KOSIS 사이트의 현재 FAQ 와 코드 설명이 어긋난다는 보고가 있다**(특히 만료 코드가 `11` 인지 `12` 인지). 실제로 막혔다면 [현재 FAQ](https://kosis.kr/openapi/community/community_0401List.do) 를 먼저 확인한다. (PDF 기준, 확인일 2026-09-20)

| 코드 | 뜻 | 조치 |
|---|---|---|
| `10` | 인증키 누락 | 키가 비었거나 오타. 설정을 다시 저장한다 |
| `11` | 인증키 기간 만료 | 활용신청 유효기간(2년)이 지났다. 만료 한 달 전이라면 마이페이지에서 연장하고, **이미 만료됐다면 활용신청을 다시 한다** |
| `20`·`21` | 요청변수 누락·오류 | 허브의 버그다. 이슈를 열어라 |
| `30` | 조회결과 없음 | 검색어를 바꾼다. 키 문제가 아니다 |
| `31` | 조회결과 초과 | 호출 건수를 줄인다 |
| `40` | 호출가능건수 제한 (분당 200건) | 공용 키를 여럿이 함께 쓰면 먼저 만난다. 잠시 뒤 다시 부르거나 개인 키로 바꾼다 |
| `41` | ROW 수 제한 | KOSIS 관리자 문의 |
| `42` | 사용자별 이용 제한 | 키뿐 아니라 **IP 제한**일 수도 있다. KOSIS 관리자 문의 |
| `50` | 서버 오류 | 상류 장애다. 허브 설정 문제가 아니다 |

## 준비 중인 도구

카탈로그에 자리는 있으나 어댑터가 없어 비공개(`enabled=False`)인 도구다. 공개될 때 이 문서에 절차를 더한다.

| 도구 | 출처 | 키 |
|---|---|---|
| 환율 (`fx`) | 서울외국환중개 | 미정 — 어댑터 확정 시 기재 |
| 유가 (`fuel`) | 오피넷 | 미정 — 어댑터 확정 시 기재 |

## 새 도구를 더할 때 (기여자용)

자격증명이 필요한 도구를 카탈로그에 넣는다면 **이 문서에 한 절을 반드시 함께 추가한다.** 아래를 채운다.

1. 설정 키 이름(`<TOOL>_API_KEY`)과 공용 키 환경변수(`SHARED_<설정 키>`)
2. 발급처 URL · 비용 · 승인 방식(자동/심의) · 유효기간
3. 번호 매긴 발급 절차 — 실제로 한 번 발급해 보고 화면에 보이는 메뉴 이름 그대로 적는다
4. 공용/개인 두 길의 입력 방법
5. 막혔을 때 표 — 그 API 의 키 관련 오류 코드를 어댑터가 내는 `error_code` 와 대응시킨다

`.env.example` 의 `SHARED_*` 항목에도 같은 키를 추가한다.
